## 1. Seed parameterization — confirmed working

`build_phase7_set(input, ..., seed=N)` regenerates the complete window
set under any seed with identical structure:

| seed | n_windows | matrix | lag | flagged expected-FN |
|---|---|---|---|---|
| 42, 123, 7, 11, 2024, 314, 2718, 999, 555, 777 (all 10) | 110 | 30 | 80 | 16 |

Verified that the seed actually changes the generated windows: the
`category_shift` and `normal_noise` matrix windows differ byte-for-byte
between seed 42 and seed 123. The seed threads into the stochastic
injectors (`inject_category_shift`, `inject_normal_noise`,
`inject_range_violation`, `inject_domain_violation`).

**Important structural caveat (read before citing):** the seed does
NOT re-sample window *placements*. Matrix starts are a fixed
`np.linspace` grid and lag streams use fixed dataset regions
(`LAG_REGION_BASE + stride * index`); only the injector draws vary.
So this sweep re-rolls *which rows get perturbed* inside the same 110
windows — it does not draw new windows from the dataset. The effective
sample size (110 windows, 3–5 per subtype) is unchanged by this
exercise. Zero cross-seed variance therefore demonstrates decision
stability under injector re-rolls, NOT statistical power from more
independent windows.

## 6. Headline question: is seed 42's B4 F1 = 0.938 representative?

**Yes — exactly.** The multi-seed mean of B4 adjusted F1 is
0.9375 with std 0.0000; seed 42's value (0.9375) equals the mean and
the min/max of all 10 seeds. Seed 42 was neither unusually favorable
nor unfavorable for any config, metric, or subtype.

**Why variance is exactly zero** (must be stated honestly in the
paper, not presented as "robust across seeds"):

1. Most windows are deterministic by construction: mean / variance /
   distribution shifts, all schema events, and all metadata-semantic
   events (unit_change, unit_conversion, business_meaning_change,
   range_change, allowed_domain_change) take no seed-dependent draws,
   so they are byte-identical across seeds and produce identical
   decisions.
2. The stochastic injectors (category_shift, range_violation,
   domain_violation, normal_noise) draw different rows per seed, but
   their detections are saturated: category_shift always fires chi2
   at every severity; range/domain violations always fire the
   semantic rules; normal_noise never fires anything. Which specific
   rows are perturbed never changes the decision.
3. Window placements are fixed (linspace / fixed lag regions), so no
   seed explores a different region of the reference dataset.

## 7. Recommended caveats for the paper

- Report B4 as F1 = 0.938 (adjusted) / 0.911 (raw), **stable across
  10 seeds (std = 0)** — but describe this as decision reproducibility
  under injector re-rolls, and explicitly state that the multi-seed
  repetition does not increase the number of independent windows.
- The small-n concern (3–5 windows per subtype) is **not** resolved by
  this sweep. Zero variance here does not imply the point estimates
  are reliable at the population level; it reflects a deterministic
  experimental design.
- To genuinely scale sample size (as the Section Y motivation intends),
  `build_phase7_set` would need to sample window *start positions* per
  seed (e.g., `rng.integers` over the dataset region) so each seed
  draws new windows — that is a generator change, explicitly out of
  scope for this pass (frozen thresholds/injection logic untouched).
- The 3 real blind spots stand unchanged at every seed: mean_shift
  (0 recall, unflagged), variance_shift and distribution_shift
  (adjusted 0 recall, flagged expected-FN).
