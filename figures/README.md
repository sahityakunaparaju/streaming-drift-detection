# Paper Figures

All figures are generated by a single script — **`experiments/generate_figures.py`** — which reads
directly from the result files under `results/`. No numbers are hand-copied; regenerate everything with:

```bash
PYTHONPATH=. python experiments/generate_figures.py          # writes here, figures/
```

Every figure is written as **PNG (300 DPI)** for review and **PDF (vector)** for camera-ready.

## Design conventions

- **Palette**: Okabe–Ito colorblind-safe hex codes; never red/green alone.
- **Grayscale-legible**: distinct hatches (`///`, `xx`, `//`), markers (`o s ^ D`),
  and line styles (`--`, `-.`, `:`, `-`) in addition to color.
- **Sizing**: single-column figures are 3.3 in wide (IEEE 2-column layout);
  the secondary-dataset panel is 6.9 in (double column). Base font 8 pt,
  ticks 7 pt, legends 6.5 pt — all verified readable at column width.
- **Error bars**: mean ± std over the 10-seed multiseed runs wherever those
  runs exist. Single-seed results (B5, Phase 13) are plotted without error
  bars and marked in the caption below.
- No 3D, no pies, no chart-junk.

## Caption requirements carried over from the data

- **Fig. 1**: the 24/110 flagged windows (expected false negatives under the
  shared flagging rule) are excluded from the "adjusted" bars and must be
  named in the caption — not hidden. B5's default-config degeneracy
  (FPR = 1.0) must also be stated.
- **Fig. 8**: the `*`/`†` markers must be explained in the caption with the
  two named findings above; otherwise the secondary dataset looks like a
  clean win, which it is not.
- **Figs. 3 and 9** use the canonical seed-42 tables; if error bars are
  requested, switch the loader to the multiseed aggregates noted above.

## Regeneration check

`experiments/generate_figures.py` fails loudly (non-zero exit) if any source
file is missing or malformed, so stale figures cannot silently persist after
a results change.
